# BlockScript

Визуальный блочный интерпретатор языка программирования.

## Требования

- [Node.js](https://nodejs.org/) (версия 18 или выше)
- npm (устанавливается вместе с Node.js)

## Запуск

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev
```

После запуска откроется локальный сервер (по умолчанию http://localhost:5173).

## Сборка для продакшена

```bash
npm run build
```

Результат сборки появится в папке `dist/`. Для предпросмотра собранной версии:

```bash
npm run preview
```
